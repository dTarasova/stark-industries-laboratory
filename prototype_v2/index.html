01 / Восстановите комплекс

Из двадцати сооружений только восемь входили в исходную установку. Оставьте два непересекающихся кольца по четыре здания: вокруг карусели и качелей.

  • В каждом кольце четыре здания соединены в замкнутую цепочку. У каждого здания два соседа по кольцу.
  • Между кольцами должно быть ровно два кабеля. Они не должны сходиться в одном здании: у каждого кабеля своя пара зданий, всего четыре здания.
  • Других соединений между оставшимися зданиями нет.
  • В составе обязательно должны быть фабрика B и купольный приёмник H ◉.
  • Пересечения линий вне зданий не считаются соединениями.
Видимых сооружений: 20 / 8

Допустимая топология ещё не доказывает подлинность. В архиве встречалось несколько похожих проектов.

02 / Восстановите маршруты

Геометрия подтверждена, но исходный проект ещё не установлен. Откройте слой «Калибровка»: цифры — задержки кабелей в тактах, знак Ω — фазовый преобразователь.

Документ 01 · Протокол двойного импульса
ИСПЫТАНИЕ №17

Два независимых канала от фабрики B до приёмника H. Они не имеют общих промежуточных зданий или кабелей. Каждый канал пересекает пространство между дворами ровно один раз, по кратчайшему доступному маршруту для своего перехода. Основной импульс приходит за 7 тактов, резервный — позднее.

Документ 02 · Акт тепловых испытаний
ОТДЕЛ БЕЗОПАСНОСТИ

В рабочем проекте ни один кабель любого из каналов не имел задержку 6 тактов или более. Проверяйте каждый участок отдельно, а не общую сумму задержек.

Документ 03 · Ведомость фазового резонанса
ЛИЧНЫЙ АРХИВ Г. СТАРКА

Станции с символом Ω — фазовые преобразователи. Их наличие на канале зависит от того, какие здания вошли в маршрут. Допускается не более одного преобразователя на канал. Два на одном канале вызывают резонанс даже через промежуточные здания.

03 / Найдите проекцию

Каналы синхронизированы. Пространственные фрагменты нового элемента проявились над комплексом, но не складываются в единую форму при произвольном ракурсе.

Оптический журнал · Запись 0

Середины двух переходов определяют створ. Смотреть нужно перпендикулярно ему со стороны фабрики. За каждый такт разности задержек резервного и основного каналов угол наблюдения повышается на 6° над горизонтом. Совместите все части единой структуры.

Включите «Створ переходов», при необходимости используйте «Вид сверху» для определения направления, затем вручную поверните модель.
