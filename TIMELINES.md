# Симулятор временных линий

Отдельный экран: `/timelines`. Режим ведущей: `/timelines/debug` (прямая ссылка, отсутствует в игровой навигации; это инструмент диагностики, а не защищённая сервером область).

## Запуск

Из `website/laboratory`: `npm ci`, `npm run build`, затем `npm start` с настроенным `ADMIN_PASSWORD`. Для разработки: `npm run dev`. Временные линии работают на клиенте; изменение стадии общей миссии по-прежнему подтверждает ведущая в `/control`.

## Правила и данные

Источник: `../timeline task/temporal_lines_cards_v8_complete.md`, V8, рабочий арест `major3`. Движок `src/timeline/engine.ts` независим от React. Лицевые стороны и финальные реплики перенесены в `src/timeline/data.ts`. Исходная редакция имеет приоритет перед примерами из задания. Отдельного Python-эталона среди материалов нет.

Все 11 решений доступны при планировании, включая принцип несозданного Вижена: V8 требует выбирать его заранее. Условны результаты, а не доступность этих ответов. Поэтому изменение раннего решения сохраняет все остальные допустимые ответы. Два порядка районов можно менять до запуска; при запуске создаётся неизменная копия маршрута.

Сохранение: localStorage, ключ `surkov.timelines.v1`, версия схемы 1. Сохраняются черновик, архив, выбранный экран, открытые карточки и бумажный режим. Неизвестная версия и повреждённое сохранение безопасно начинают новый сеанс. Архив и прогресс относятся к этому браузеру и устройству, серверная синхронизация не добавлена.

## Проверки

- `npm test` — сервер и логика, включая 13 тестов временных линий.
- `npm run build` — TypeScript и сборка.
- `node timeline-balance.mjs` — полный перебор ответов с двумя фиксированными порядками районов, распределение финалов, достижимость аномалий и детерминизм. Перестановки приоритетов в число основных линий не входят. Вычисляются 349 920 формальных и 233 280 основных различимых маршрутов.

Режим диагностики предлагает контрольные маршруты F1–F8, случайное заполнение, мгновенный отчёт и сброс. На обычном экране численные характеристики доступны только в итоговом техническом отчёте и на раскрытых оборотах карточек.

## Границы проверки

Симулятор не меняет баланс и не подтверждает автоматически прохождение общей миссии. Режим диагностики доступен по известному адресу без отдельного пароля. Общий экран лаборатории и управление миссией остаются отдельными. Автоматический перебор подтверждает внутреннюю согласованность реализации, но не заменяет независимый эталон расчёта. Проверка браузером в этой среде не выполнена: локальный адрес недоступен средству предпросмотра.
